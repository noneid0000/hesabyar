# حساب‌یار — Android APK

این پروژه نسخه وب حساب‌یار را با Capacitor داخل Android قرار می‌دهد.

## ساخت APK با GitHub Actions

فایل‌های پروژه را داخل repository قرار دهید و به branch `main` push کنید. Workflow به‌صورت خودکار اجرا می‌شود و APK را در بخش **Artifacts** همان Run قرار می‌دهد.

برای اجرای دستی نیز از **Actions → Build Hesabyar APK → Run workflow** استفاده کنید.

APK خروجی:
`android/app/build/outputs/apk/debug/app-debug.apk`
